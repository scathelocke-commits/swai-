# 실제 동작과 목업 기능의 구분표

| 기능 | 구분 | 세부 동작 | 주의사항 |
|---|---|---|---|
| 6개 페이지 렌더링 | 실제 UI 구현 | App Router 경로마다 독립 페이지 | 로컬 의존성 설치 필요 |
| 모바일 반응형 내비게이션 | 실제 UI 구현 | 모바일 하단 5개 메뉴·데스크톱 사이드바 | 설정은 헤더에서 접근 |
| 학적정보 입력/저장 | 실제 클라이언트 기능 | 드롭다운, 입력값 저장 및 새로고침 복원 | 실제 학사규정 변경 없음 |
| 수강내역 CRUD | 실제 클라이언트 기능 | 추가·수정·삭제·검색·필터링, 입력 검증 | 실제 이수학점 판정에 반영하지 않음 |
| localStorage | 실제 클라이언트 기능 | 가상 입력 저장 및 초기화 | 다른 기기/브라우저와 동기화하지 않음 |
| FastAPI JSON 응답 | 실제 서버 기능 | GET 7개 기본 경로와 2개 시나리오 경로 | 읽기 전용 데모 데이터 |
| API 연결 실패 시 폴백 | 실제 클라이언트 기능 | 동일한 내장 JSON 데이터 사용 | API 연동 시연은 불가 |
| 영역별 학점 카드 및 진행바 | 고정 데모 데이터 | 시나리오 데이터에서 수치를 표시 | 사용자 입력과 독립 |
| 총 졸업학점 및 학번별 졸업요건 | 고정 데모 데이터 | 총 130학점의 가상 규정 | 단국대학교 규정 아님 |
| 3종 졸업요건 충족 분석 | 고정 데모 데이터 | 시나리오 선택에 따라 결과 전환 | 판정 알고리즘 없음 |
| 부족학점/미이수 필수과목 | 고정 데모 데이터 | 시나리오에 정의된 값 조회 | 재수강·중복 계산 없음 |
| 학기별 추천 로드맵 | 고정 데모 데이터 | 시나리오별 3개 학기 카드 표시 | 최적화·개설학기·선수과목 검증 없음 |
| 회원가입/로그인 | 제외 | 구현하지 않음 | 개인정보 수집하지 않음 |
| 공식 포털 시스템 연동 | 제외 | 구현하지 않음 | OAuth·학사DB 접속 없음 |

## 시연 권장 순서

홈 대시보드 → 학적정보 변경/저장 → 수강내역에 교과목 추가 → 졸업요건 조회 → 졸업분석 시나리오 1·2·3 전환 → 로드맵 확인 → 홈으로 이동 → 새로고침하여 저장 상태 확인.

분석 버튼과 추천 버튼은 사용자 입력에 따른 실제 계산을 수행하지 않는다는 사실을 발표 중 명확히 설명한다.
